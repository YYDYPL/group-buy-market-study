# 随机拼团队伍轮播

## 变更信息

- 变更时间：2026-07-27 17:50:14 +08:00
- 变更范围：商品详情页进行中队伍展示、营销配置候选数量和 README
- 兼容范围：Java 8、Spring Boot 2.7、原生 HTML/CSS/JavaScript 前端

## 变更内容

- 营销配置接口保留最多 1 支当前用户队伍，并将其他随机候选从 2 支扩展到 6 支，为前端轮播提供候选池。
- 商品详情页按照 `teamId` 去重并随机排列候选队伍，每屏固定展示 2 支，每 4 秒纵向切换一屏。
- 奇数支候选队伍会将最后一支与首支组成下一屏，保证候选不丢失且每屏仍展示 2 支；恰好 2 支时通过交换顺序轮播，只有 1 支时保持静态展示。
- 队伍发起人在本地模拟用户列表中存在时显示昵称并以昵称首字符生成头像，未匹配的历史用户回退为脱敏拼友名称。
- 轮播刷新时统一销毁旧轮播和倒计时任务，倒计时改为基于结束时间计算，避免重复定时器和后台标签页计时漂移。
- 队伍区域固定为两行高度并隐藏溢出，轮播后“去拼单”按钮继续携带对应的原始 `teamId`。
- README 增加随机双队伍轮播和本地昵称展示说明。

# 拼团商城与运营后台迁移

## 变更信息

- 变更时间：2026-07-27 12:04:01 +08:00
- 变更主题：将参考项目中已经验证的拼团商城、商品配置和运营后台能力迁移到当前重写项目
- 适用环境：Java 8、Spring Boot 2.7、MySQL 8、Redis 6.2、RabbitMQ 3.12

## 变更内容

1. 新增数据库驱动的商城商品查询、商品详情、管理分页、组合草稿、优惠试算、发布、下架和废弃能力。
2. 商品配置使用版本号进行乐观锁校验；发布、下架及渠道映射切换由事务保护，并删除活动与优惠缓存。
3. 新增 `X-Admin-Token` 管理令牌过滤器，使用摘要和常量时间方式比较令牌；令牌为空时管理接口默认关闭。
4. 新增 JPG、PNG、WebP 图片上传，限制单文件 5MB，并校验扩展名、Content-Type、文件签名和规范化目标路径。
5. 增加商城与后台 CORS 配置，并将上传目录映射为 `/uploads/**` 静态资源。
6. 新增幂等数据库升级脚本，扩展商品展示、活动草稿、配置版本和渠道状态字段，导入 8 款本地演示商品及对应活动。
7. 将升级脚本作为第二个 MySQL 初始化脚本挂载，并在脚本内显式设置 `utf8mb4`，避免中文种子数据乱码。
8. 完成移动商城首页、商品详情、运营后台登录和配置页面，复用 8 张本地商品主图，不依赖外部图片地址。
9. 更新应用 multipart、后台令牌、上传目录、应用容器卷和 README 运行说明。
10. 新增后台令牌、四种优惠策略、仓储事务/缓存和安全上传共 16 个自动化测试。

## 运行说明

- 本地启动应用前必须设置 `GBM_ADMIN_TOKEN`，否则管理接口返回服务未配置结果。
- 商城目录为 `docs/dev-ops/nginx/html`，使用静态服务器启动后访问根路径；后台入口为 `/admin/login.html`。
- 已有 MySQL 命名卷不会自动重放初始化目录，需要按 README 手动执行幂等升级脚本。
- 全量测试会修改共享 DCC 值；测试结束后应确认 `group-buy-market_downgradeSwitch=0`。

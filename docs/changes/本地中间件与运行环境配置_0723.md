# 本地中间件与运行环境配置

## 变更信息

- 变更时间：2026-07-23 19:46:44 +08:00
- 变更类型：本地开发环境、数据库初始化、运行配置与启动阻断修复
- 适用环境：Windows、Docker Desktop、JDK 8、Spring Boot `dev` 环境

## 变更内容

### Docker 中间件

- 将 `docs/dev-ops/docker-compose-environment.yml` 收敛为 MySQL、Redis、RabbitMQ 三个核心服务。
- MySQL 使用 `127.0.0.1:13306`，账号 `root`，密码 `123456`。
- Redis 使用 `127.0.0.1:16379`，不设置密码。
- RabbitMQ 使用 AMQP 端口 `127.0.0.1:5672` 和管理端口 `127.0.0.1:15672`，账号密码为 `admin/admin`。
- 为三个服务增加健康检查、本地端口绑定、自动重启、时区和稳定命名卷。
- 将原 MySQL、Redis 匿名卷数据迁移到 `dev-ops-mysql-data`、`dev-ops-redis-data`，并创建 `dev-ops-rabbitmq-data`。
- 保留原匿名卷、其他数据库和 Redis 已有键，未执行 `FLUSHDB` 或 `FLUSHALL`。

### 数据库初始化

- 使用 `docs/dev-ops/mysql/sql/2-29-group_buy_market.sql` 作为当前权威结构来源，更新主初始化脚本 `group_buy_market.sql`。
- 仅删除并重建 `group_buy_market` 数据库，导入 10 张业务表及测试数据。
- Compose 只挂载主初始化脚本，避免多份 SQL 重复覆盖表结构。
- 核验了 `group_buy_order`、`group_buy_order_list` 和 `notify_task` 的订单、退款、通知相关字段。

### 应用配置

- `application-dev.yml` 改为本机可直接运行的默认配置，并支持通过环境变量覆盖 MySQL、Redis、RabbitMQ 连接信息。
- JDBC 本地连接关闭 SSL，并保留 UTF-8、时区和连接参数。
- RabbitMQ 应用连接端口修正为 AMQP `5672`。
- xfg-wrench 动态配置中心与应用 Redis 统一连接 `127.0.0.1:16379`。
- dev 和 test 环境不再连接 Logstash，prod 环境继续保留 Logstash 输出。

### 构建与代码修复

- 为 `logstash-logback-encoder` 固定兼容 Java 8 和 Spring Boot 2.7 的 `7.3` 版本。
- 修正 MyBatis Mapper XML 中残留的内部旧包名。
- 将 `nofify_task_mapper.xml` 更名为 `notify_task_mapper.xml`。
- 修正测试源码、内部 `package-info`、活动服务实现类名、缺失 import 和错误的 `@Value` import。
- 保留真实第三方依赖包名 `cn.bugstack.wrench`。
- `TradeSettlementOrderService` 的现有实现已纳入编译和启动验证。
- Maven 测试默认仍跳过，但现在允许使用 `-DskipTests=false` 显式运行指定测试。
- 新增通知任务 DAO 只读查询测试，补齐活动、优惠和通知任务三类 Mapper 验证。

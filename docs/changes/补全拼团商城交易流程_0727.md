# 补全拼团商城交易流程

## 变更信息

- 变更时间：`2026-07-27 13:04:35 +08:00`
- 变更主题：补全本地多用户拼团、锁单待支付、订单查询、退款和历史统计
- 兼容范围：Java 8、Spring Boot 2.7、本地 MySQL/Redis/RabbitMQ 和原生静态前端

## 变更内容

- 新增浏览器本地模拟用户中心，可注册、切换和删除多个测试身份，并保留邀请返回地址。
- 商品详情页增加独立锁单成功阶段，不再锁单后自动支付；支持稍后支付、邀请好友、团队成员详情和继续支付。
- 新增商城订单中心，支持全部、待支付、已支付和已关闭订单查询，以及取消锁单、继续支付和申请退款。
- 新增用户订单分页与团队详情 API，返回订单操作标记、团队进度及成员状态。
- 锁单通知改用 RabbitMQ，修复重复锁单响应缺少团队 ID、通知配置为空异常和无效团队参团校验。
- 活动统计改为历史累计口径：所有已创建团队、正常成团及成团后退款团队、全部参团订单均保留在统计中。
- 新增幂等数据库脚本 `3-1-store-order-flow.sql`，为团队成员查询补充 `idx_team_id` 索引。
- README 增加多用户完整拼团体验、订单中心、新 API 和数据库升级说明。
